# منظم الإيصالات والحوالات البنكية الآلي (SNB & General Receipts Organizer)

تطبيق بلغة Python لبرمجة وأرشفة إيصالات الحوالات والمدفوعات البنكية (مثل إيصالات البنك الأهلي السعودي SNB) آلياً. يقرأ السكربت ملفات PDF، ويستخرج بياناتها المالية والمستفيدين، ثم يعيد تسمية الملفات بطريقة منظمة، وينشئ تقريراً مالياً متكاملاً في ملف Excel منسق جاهز للاستخدام المحاسبي.

---

## 🌟 الميزات الرئيسية

* **التعرف الآلي الذكي على أنواع العمليات:**
* **التحويلات البنكية المباشرة (NCB/SNB):** استخراج اسم المستفيد والمبلغ بدقة.
* **الحوالات المحلية (Local Transfers):** التمييز الآلي للحوالات بين البنوك المحلية.
* **المدفوعات الحكومية (MOI):** استخراج نوع الخدمة (مثل تجديد إقامة، رخص) واسم المستفيد أو الجهة الحكومية.


* **معالجة الحوالات المجمعة:** التعرف على الإيصالات التي تضم أكثر من مستفيد واحد، وحساب إجمالي المبالغ مع إعادة تسمية الملف لتوضيح أنها "حوالة مجمعة".
* **استخراج الملاحظات وأرقام المراجع:** قراءة الملاحظات المكتوبة على الإيصال ورقم مرجع العملية تلقائياً.
* **إعادة تسمية الملفات وتوحيد المسميات:** تنظيم اسم كل ملف PDF ليكون بالشكل: `التاريخ - المستفيد (الملاحظات) - المبلغ.pdf` مع تنظيف الأسماء من الرموز والمسافات الزائدة وإضافة ترقيم آلي لمنع تكرار الملفات.
* **توليد تقرير إكسيل (Excel) احترافي:**
* تنظيم البيانات في جدول يتجه من اليمين إلى اليسار (RTL).
* تنسيق تلقائي للأسطر (Zebra Striping) وعناوين مميزة.
* تطبيق تنسيق الأرقام والعملات (`#,##0.00`).
* حساب الإجمالي العام آلياً باستخدام صيغ إكسيل (`=SUM(...)`).
* ضبط تلقائي لـ عرض الأعمدة لتناسب حجم النصوص.


* **هيكلة تلقائية للمجلدات:** إنشاء مجلد للشهر الحالي آلياً داخل مسار العمل أو سطح المكتب لتنظيم الأرشفة الشهرية بدون تدخل يدوي.

## 🛠️ المتطلبات والأدوات المستعملة

* **Python 3.8+**
* المكتبات البرمجية المطلوبة:
```bash
pip install pdfplumber openpyxl

```



---

## 🚀 طريقة التشغيل

1. ضع كافة إيصالات الـ PDF المراد أرشفتها داخل المجلد الآلي المخصص للشهر (أو سيقوم السكربت بإنشائه تلقائياً في المسار المحامي المعتمد).
2. شغل السكربت عبر الأمر:
```bash
python main.py

```


3. ستقوم الأداة بـ:
* طباعة حالة كل ملف وإعادة تسميته فوراً.
* إنشاء ملف إكسيل بجميع الحركات المالية بأسماء واضحة ومدروسة.
